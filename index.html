▌ CÓMO EJECUTAR LA HERRAMIENTA REAL (terminal)

Esta página es una demo visual simulada. El programa real es netspectre.py en la raíz del repositorio y se ejecuta desde tu terminal:

# 1) abre una terminal en la carpeta del proyecto
cd /ruta/a/NetSpectre

# 2) modo interactivo (REPL estilo Metasploit)
python3 netspectre.py

#    o indica el objetivo desde el inicio:
python3 netspectre.py --target 192.168.1.0/24

# 3) escaneo automático sin menú (hosts + puertos) y sale
python3 netspectre.py --plain

# extras: --no-color · --log eventos.txt · --version

Comandos dentro del REPL: help · hosts [cidr|ip] · ports [cidr|ip] [rango] · osint · set <opción> <valor> · status · history · save [report.json] · clear · exit

Permisos: el escaneo TCP funciona sin privilegios. Para el barrido ICMP (set ping_sweep on) se necesita sudo (Linux/macOS) o ejecutar como Administrador (Windows).

⚠ Uso autorizado únicamente: audita solo redes propias o con permiso explícito.
